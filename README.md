# **Torch Button 🔦**

A minimal Android app that instantly turns on the flashlight when launched.

Built as a proof of concept for Motorola's dedicated AI Button.
Assign this app to the button and double-press it to turn on the torch instantly, even while the phone is locked.

**Why?**

Motorola's AI Button can launch apps, but doesn't currently provide a direct flashlight action. 
This app bridges that gap with a simple, zero-friction shortcut.

Tested on: Motorola Edge 70
Built with: Kotlin + Android CameraManager
